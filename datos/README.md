# Datos

La parte de datos del curso tiene dos proyectos independientes. Cada uno tiene su propio
`README.md`, su base de datos y su configuración de agentes: abre el agente **dentro de la
carpeta del proyecto**, no aquí.

| Carpeta | Proyecto | Para qué |
|---|---|---|
| [`InfraData/`](InfraData/README.md) | Analítica de sensores | Python sobre PostgreSQL + TimescaleDB |
| [`ReportingBI/`](ReportingBI/README.md) | Informes de Power BI | Modelo e informes de Power BI sobre la base de datos de un ERP tipo Navision |
